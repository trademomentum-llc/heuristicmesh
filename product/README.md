# HeuristicMesh Consumer Fall Sensor
## Product Definition Package

This folder contains the complete consumer-product definition for a small, manufacturable home fall-detection node based on the AMG8833 + ESP32 architecture.

### Files
- `01-product-brief.md` – goals, constraints, pricing target
- `02-electronics-schematic.md` – block diagram, power, I2C, BOM
- `03-mechanical.md` – form factor, mounting, thermal design
- `04-bom-summary.md` – cost target at volume

### Design Intent
Privacy-first, low-cost, wall/ceiling mountable thermal node that can be produced at consumer price points while feeding the HeuristicMesh backend (Jetson / hub / cloud) for final event confirmation and alerting.
