=== Component Placement Coordinates

--------------------------------------------------------------------------------------------------
| Component              | Breadboard Position | Connections                          |

| ESP32-S3 DevKitC-1     | A1-J30               | USB, 3.3V, GND, GPIO 8,9,43,44,2     |

| AMG8833 #1 (0x69)      | L1-S15               | VDD(3.3V), GND, SDA, SCL, AD0(3.3V)   |
| AMG8833 #2 (0x68)      | L16-S30              | VDD(3.3V), GND, SDA, SCL, AD0(GND)    |
| AMS1117-3.3V           | E1-E5                | IN(5V), OUT(3.3V), GND               |
| 1N4007 Diode           | D1-D3                | Anode(5V in), Cathode(5V rail)        |
| 10uF Capacitor         | E6-F6                | 5V rail to GND                        |
| 47uF Capacitor         | E7-F7                | 5V rail to GND                        |
| 100nF Capacitor        | G8-H8                | 3.3V rail to GND                       |
| LED1 (Power)           | A60-B60              | Anode(220R->3.3V), Cathode(GND)       |
