# Fall Simulation Scenarios (Production)

## Tier 1 – Common
- S01 Forward trip
- S02 Sit-to-stand failure
- S03 Lateral slip

## Tier 3 – Elusive (high value)
- S06 Slow syncope / controlled collapse
- S10 Controlled descent vs true fall (negative class)

## Protocol Notes
- Actor remains still 4–6 s after impact
- Record continuous body-cam footage
- Log wall-clock start + scenario order
- Prefer mat for higher-risk trials
